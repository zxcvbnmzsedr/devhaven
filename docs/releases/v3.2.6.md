# DevHaven v3.2.6

- 减少安装包下载体积与 App 磁盘占用。发布打包会清理调试符号、局部符号和 Swift 编译模块，并保留运行所需的动态入口与资源。
- 本地 Apple Silicon Release 对比：App 文件总大小从 340.1 MiB 降至 212.9 MiB，减少约 37.4%；ZIP 安装包从 95.6 MiB 降至 72.4 MiB，减少约 24.2%。不同架构的实际体积有所不同。
- 已验证项目打开、终端输入与分屏、shell 退出与重新打开、粘贴及签名校验。

提供 Apple Silicon、Intel 和 Universal 安装包。Universal 安装包可用于两种架构的 Mac。
