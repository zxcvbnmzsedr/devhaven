# DevHaven v3.2.4

本版本修复 v3.2.3 在 GitHub Actions 中的构建失败，并包含原计划发布的功能与修复：

- 新增分组终端和分组 Codex 入口，可在一个会话中协同处理组内多个项目，保留各项目原有终端。
- 分组协同目录自动维护成员清单，并为 Codex 配置成员真实目录的访问范围。
- 修复内嵌终端的桌面通知与未读标记，支持 BEL、OSC 9 和 OSC 777，收到后台通知时保持当前输入焦点。
- 修复 `⌘K` 打开项目的快捷键和菜单启用状态，支持修改快捷键后即时生效。
- 修复 cmux 静态框架依赖的准备与架构校验，兼容 GitHub Actions 使用的 Xcode 工具链。

提供 Apple Silicon、Intel 和 Universal 安装包。Universal 安装包可用于两种架构的 Mac。
